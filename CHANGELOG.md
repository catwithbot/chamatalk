# Chamatalk changelog

## 0.2.0 - 2026-09-26

- Switched the branded image base to Chatwoot Community Edition (`latest-ce`).
- Removed the Enterprise image dependency from the Chamatalk Docker build.

## 0.1.0 - 2026-09-26

- Added Chamatalk installation branding.
- Added Chamatalk horizontal white logo.
- Added Chamatalk symbol for favicon, PWA, and entry pages.
- Added a derived Docker image definition for the branded installation.
- Updated the production Compose stack to use the branded image.
